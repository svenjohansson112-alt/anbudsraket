ANBUDSRAKET AI – PILOT

Detta repository innehåller en fristående HTML-prototyp för att söka och sålla bland offentliga EU-upphandlingar via TED Search API.

START
- Öppna index.html i en modern webbläsare.
- Tryck på "Sök annonser".
- Kontrollera alltid originalannonsen och hela upphandlingsunderlaget.

BEGRÄNSNINGAR
Detta är inte en färdig SaaS eller intäktsgenererande tjänst.
Ingen inloggning, kunddatabas, schemalagd bevakning, e-postnotiser, betalning,
serverfunktion eller AI-dokumentanalys finns ännu.
API-anropet är inte verifierat i produktionsmiljö. Om webbläsaren blockerar
anropet behövs en serverproxy. TED täcker inte alla svenska nationella annonser.
Matchningen är endast en försortering och ingen juridisk bedömning eller garanti.
