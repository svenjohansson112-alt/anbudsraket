## Full description (250+ words)

AnbudsRaket AI is an early-stage working web MVP for discovering public procurement opportunities, initially aimed at small Swedish service businesses such as cleaning, local-care, window-cleaning and painting companies. It uses the EU TED Search API as its data source and provides keyword and CPV filtering, relevance sorting, publication-date filters, deadline and CPV display when those fields are available, CSV export, and a simple calculator for estimating revenue, labour cost and surplus on a potential contract.

The project is pre-revenue. It has no paying customers and no established customer base or audience. There is no validated subscription model, no recurring revenue and no claim of production readiness. The existing demo is publicly accessible and the source repository is also public, so interested buyers can inspect the current implementation before discussing a deal.

The technical stack is intentionally simple: HTML, CSS and JavaScript, hosted through GitHub Pages, with a GitHub Actions workflow intended to retrieve TED data and publish a static data file. Important limitation: recent scheduled workflow runs have failed. The data-refresh pipeline needs to be inspected and stabilised by a new owner, and the freshness of the currently published data must not be assumed. Coverage is limited to TED and a selected search period; it does not provide complete coverage of Swedish national procurement portals. Location matching is basic text matching, relevance scoring is heuristic, and the product does not perform AI analysis of complete tender documents. There are no user accounts, saved searches, email alerts, payment processing or customer-support operations. Deadlines and all tender details must be checked against the original notice.

A buyer could use the project as a starting codebase for a narrow Swedish tender-discovery tool, a lead-generation front end, a white-label experiment or a feature to integrate into an existing procurement or vertical-software product. Any future subscription, licensing or lead-generation model remains unvalidated and would require product work and customer research.

The asking price is USD 1,900, negotiable for a quick and uncomplicated transaction. The exact assets and support included will be agreed in writing. The public repository means the code is already viewable; no claim of exclusive secrecy is made. No account, repository ownership, domain or other asset will be transferred before the terms are agreed and payment is verified.
