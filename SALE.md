# AnbudsRaket AI — software asset for sale

AnbudsRaket AI is an early-stage working web MVP for discovering public procurement opportunities, initially aimed at small Swedish service businesses such as cleaning and painting companies.

## Included in an asset sale

- Publication-date filters, deadline/CPV display when available
- CSV export and simple profitability calculator
- Existing TED API/data-fetching workflow and GitHub Pages demo
- Project name and current assets, subject to agreed transfer terms

## Technology
HTML, CSS, JavaScript, GitHub Pages, GitHub Actions, TED Search API.

## Honest status
- Pre-revenue; no paying customers and no established user base.
- This is an MVP/pilot, not a production SaaS business.
- Coverage is TED-based and does not include all Swedish national procurement notices.
- Location filtering is basic text matching, not verified geographic search.
- Relevance scoring is heuristic; there is no AI analysis of full procurement documents.
- Automated data refresh has had recent workflow failures; reliability should be checked and improved by the buyer.
- Always verify deadlines and details against the original procurement notice.
